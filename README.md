# Banking Transfer System Analysis

A system analysis pet project focused on designing an internal
money transfer module for a mobile banking application.

The module enables clients of the same bank to transfer funds,
find recipients by phone number, track transfer limits,
view transaction history, and receive transfer notifications.

The project includes business and system requirements,
user stories, use cases, BPMN/UML diagrams, ERD,
REST API specifications, SQL, and integration design.
