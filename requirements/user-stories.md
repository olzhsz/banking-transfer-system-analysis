# User Stories

## US-001 — Recipient Search

As a bank client, I want to find a transfer recipient by phone number,
so that I do not need to know their card details.

## US-002 — Transfer Notification

As a bank client, I want to be informed about the result of my transfer,
so that I do not need to repeatedly open the application to check its status.

## US-003 — Transfer Limit

As a bank client, I want to see my remaining monthly transfer limit,
so that I can plan my transfers accordingly.

## US-004 — Transfer History

As a bank client, I want to view my transfer history,
so that I can review my previous transfers when needed.
